1.1 · What Is Scratch & Why Kids Love It

Q1
What is the single biggest advantage of block-based coding for children?
B) You can't make syntax/typing errors that break the program
Why: blocks only snap together when the combination is valid, so there's nothing to misspell. Speed (A) and cost (C) aren't what makes blocks different from typing.
Q2
In Scratch, what does a block's color tell you?
B) Which category it belongs to (Motion, Looks, Events…)
Why: blue is Motion, purple is Looks, gold is Events, and so on. The order comes from how blocks are stacked, not from their color.
Q3
What's the best first-session goal with your child?
C) Create one moment of "whoa, I made that!"
Why: that feeling is the hook everything else builds on. A finished game or memorized vocabulary puts too much pressure on day one.
Q4
In Scratch, the orange cat is an example of a…
B) Sprite
Why: a sprite is any character or object you can code. The stage is the screen it acts on, and blocks are the instructions. Anyone who picks A is usually mixing up "the thing" with "where the thing is", so point at each one on the projector.
Lab notes — Click around (no file)

Success = each participant has dragged at least one block into the code area, clicked it, and tried to snap a hat block under another block (it won't go). Coach the frozen participant by putting a mouse in their hand and saying "Drag anything. You can't break it." Check the Teach-It pitch for three things: it leads with the child's interest, uses "make" rather than "learn", and ends with a question.

1.2 · A Guided Tour of the Scratch Editor

Q1
Nothing happens when your child runs their blocks. Most likely cause?
B) The code is on a different sprite than the one selected
Why: code lives on the selected sprite, so check the sprite list first. Scratch has no paid tier (A), and the internet (C) isn't the usual culprit.
Q2
Which button runs the project?
A) The green flag
Why: the flag starts every when ⚑ clicked script. The red stop halts everything; the Costumes tab switches to a sprite's outfits.
Q3
What does a block's category color help you do?
B) Quickly find the kind of block you need in the palette
Why: color groups blocks, and the colored dots jump the palette to each group. Color doesn't affect speed, and saving lives in the File menu.
Q4
You're not signed in. How do you keep today's project?
C) File → Save to your computer
Why: this downloads a .sb3 file you can reopen with File → Load from your computer. Accounts are optional (A is wrong), and only signed-in projects save to the cloud (B is wrong).
Lab notes — Point and Name + Save & reload (no file)

Correct labels: 1 Blocks Palette (left), 2 Code Area (middle), 3 Stage (upper right), 4 Sprite List (lower right). The default cat has 2 costumes. The category menu shows 9 colored dots (Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks), plus more if extensions are added. The program-starter block is when ⚑ clicked in gold Events. Save is done when the participant has reopened the .sb3 with Load from your computer, or sees their project under My Stuff.

Common wrong turns: swapping "stage" and "sprite list" in the sketch (have them click a sprite in the list and watch the code area change); a saved file they can't find (open Downloads together); calling the Code Area "the stage".

1.3 · Your First Project: Make the Cat Move & Talk

Q1
Which block goes at the top so the script runs on the green flag?
B) when ⚑ clicked
Why: the "hat" block starts the program. move and say are action blocks that go underneath it.
Q2
Scratch runs the blocks in a stack…
A) from top to bottom, in order
Why: this is a sequence, the most basic idea in coding. Order is behavior.
Q3
The cat moves but won't talk. Best first check?
B) Is the "say" block snapped onto the stack?
Why: a block sitting loose, even a few pixels away, doesn't run with the stack. Drag the hat: anything that doesn't come along isn't attached.
Q4
say … for 2 seconds is dragged above move 50 steps. What happens?
C) The cat talks first, then walks
Why: the timed say block finishes its 2 seconds before the next block starts, so the steps happen one after another. B is a good wrong answer to discuss, because running things "at the same time" needs two scripts (Module 2).
Lab solution — Make the Cat Move & Talk

Reference: labs/module-1/l1-3-cat-move-talk.sb3. One sprite (the default cat, Sprite1) on the default white backdrop, with the lesson's finished script. Clicking the green flag makes the cat walk 50 steps to the right and then say its message for 2 seconds.

when ⚑ clicked
move 50 steps
say Hello! I'm Scratch Cat for 2 seconds
when ⚑ clicked
go to x: 0 y: 0
move 50 steps
next costume
start sound Meow
say Hello! I'm Scratch Cat for 2 seconds

Accept any version where the hat is on top, move and say are snapped under it, and the message is the participant's own. "Make it yours" additions (a second say, change size by 25, turn ↻ 15 degrees) are all fine anywhere under the hat.

Common wrong answers & how to coach them

Floating blocks (they look attached but aren't). Coach: "Grab the gold block and drag it. What came with it?" Let them find the gap themselves.

Script built on the stage/backdrop instead of the cat (the Stage has no Motion blocks, so they'll be confused about where "move" went). Coach: "Which picture is highlighted in the sprite list?"

No hat block. Clicking the stack still runs it, so they think it works, but the green flag does nothing. Coach: "Press the flag. What's missing on top?"

Plain say Hello! (no seconds). The bubble never goes away. That's not wrong, just different. Ask which one they meant to use.

Cat stuck at the right edge after several runs. Coach toward go to x: 0 y: 0: "Where should the cat be at the start of every run?"

Upside-down cat after turn ↻ 15 degrees. Set the rotation style to left-right in the direction pop-up, or add point in direction 90 after the hat.
