# Module 1 Labs — Getting Started with Scratch

```
l1-3-cat-move-talk.sb3   Lesson 1.3 — the finished first program
```

**1.1** has no build: participants create an account (optional) and click around the editor.
**1.2** is the editor tour ("point and name") plus a save-and-reload check.
**1.3** — the cat's first program:

    when green flag clicked
    move 50 steps
    say [Hello! I'm Scratch Cat] for 2 seconds

Definition of done: clicking the green flag makes the cat walk and talk. Common extras participants add
(`go to x: 0 y: 0` at the top, `next costume`) are fine — see the answer key.
