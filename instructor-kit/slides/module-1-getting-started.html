What Is Scratch & Why Kids Love It

Before you teach it, understand it.

One sentence · three words

Scratch is a free website where kids make games, animations & stories by snapping blocks together

  • Sprite: a character or object (the cat)
  • Stage: the screen where the action happens
  • Blocks: the instructions you snap together
Blocks vs typing

Nothing to misspell

# typed code
when program starts:
    move(10)
    say("Hello!", 2)
when ⚑ clicked
move 10 steps
say Hello! for 2 seconds
MotionLooksSoundEventsControlSensingOperatorsVariables
COLOR = category. Kids read programs by color first.

A Guided Tour of the Scratch Editor

Four zones. Learn these and you've learned the editor.

Your map · then play "Point and Name"

The four zones

  • 1 Blocks Palette (left): pick instructions
  • 2 Code Area (middle): snap them together
  • 3 Stage (upper right): watch it happen, with ⚑ run and ● stop
  • 4 Sprite List (lower right): choose who you're coding
#1 TRAP Code belongs to the selected sprite.
Keep your work

Saving & accounts

  • No account: File → Save to your computer (.sb3)
  • Reopen: File → Load from your computer
  • Account: File → Save now
  • Kid account: your email as guardian
  • Username that hides their real name
  • Confirm the email before they can share
BLOCKED? The free Scratch app works offline: scratch.mit.edu/download

Your First Project

Make the cat move and talk.

Three blocks · a sequence

Top to bottom, in order

when ⚑ clicked
move 50 steps
say Hello! I'm Scratch Cat for 2 seconds
  • Gold hat starts it
  • Blue moves, purple talks
  • Swap them and the cat talks first
WATCH Wait for the grey shadow before you let go, or the block won't snap.
Lab · 12 minutes

Build it, then make it yours

  • Build the three-block script and click ⚑
  • Your own message · 200 steps · a second say
  • start sound Meow · change size by 25 · next costume
  • Walked off the edge? go to x: 0 y: 0 under the hat
  • Save it before you stop

Treasure hunt, not dictation

  • "Which color do you think has the moving blocks?"
  • "The message is yours. What should the cat say?"
  • "It didn't work yet. Why do you think it did that?"
RULE The words, the number and the green flag belong to the child.
