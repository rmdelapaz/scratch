Four rules · then the lab

Stamp, prints, or both?

  • Clones copy everything, even being hidden, so start with show
  • Each clone runs its own copy of the clone script
  • when ⚑ clicked runs only on the original
  • About 300 clones max: every clone must reach delete this clone

Seven steps to a real game

  • 1 Bowl, Star, Stars backdrop
  • 2 Variables: score, lives
  • 3 reset game on the Bowl
  • 4 Arrow keys move the Bowl
  • 5 Star factory (hidden)
  • 6 Each clone falls
  • 7 Catch it: +1 and a Pop!
