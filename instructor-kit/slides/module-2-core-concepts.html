Sequences & Timing

Computers follow your recipe to the letter.

Order changes everything

Same blocks, different show

when ⚑ clicked
move 100 steps
say Made it! for 2 seconds
when ⚑ clicked
say Here I go! for 2 seconds
move 100 steps
  • wait (1) seconds (orange Control) = your pacing tool
WATCH "Frozen" cat? A say-for-2-seconds block is holding, as designed.

2.2

Loops

Why drag 20 blocks when one will do?

repeat vs forever · inside the C

Only the inside repeats

repeat 3
say Ha! for 1 seconds
repeat 3
move 10 steps
say Done! for 1 seconds
  • repeat: you know how many
  • forever: until the red stop
  • Nothing after forever ever runs
WATCH Trackpad trouble nesting into the C? Grab a mouse.

Conditionals & Sensing

The moment a project becomes a game.

forever + if = the game loop

Keep asking, react instantly

when ⚑ clicked
forever
if touching mouse-pointer? then
start sound Meow
if key space pressed? then
say Jump! for 1 seconds
else
say Waiting… for 1 seconds
READ IT ALOUD Hexagon = a true/false question (light-blue Sensing). Else = "otherwise."
Lab 2.3 · l2-3-arrow-key-cat.sb3

Drive the cat

when ⚑ clicked
forever
if key right arrow pressed? then
change x by 10
if key left arrow pressed? then
change x by -10
if key up arrow pressed? then
change y by 10
if key down arrow pressed? then
change y by -10
  • Build one arrow, test, then right-click → Duplicate
  • Left/right = x; up/down = y
  • Challenge: if touching edge, say "Ouch!"
WATCH Cat won't move? Click the stage once (keyboard focus).
